# 🎥 Video Chat App

A lightweight, real-time **video conferencing web app** built using **Node.js**, **Express**, **Socket.io**, and **PeerJS**.  
This app allows users to instantly create or join video chat rooms and communicate via video, audio, and messages — all within their browser.

---

## 🚀 Live Demo  
👉 **[Click here to open the live app](https://video-chat-app-dsrm.onrender.com/)**

---

## 🧩 Features
- 🎞️ Real-time video and audio communication (WebRTC-based)
- 💬 Live text chat inside the video room
- 👥 Room-based video calling (unique room IDs)
- ⚡ Peer-to-peer connection using **PeerJS**
- 🧠 Built with **Express** and **Socket.io**
- 🖥️ Fully responsive and minimal interface
- ☁️ Hosted on **Render (Free Tier)**
